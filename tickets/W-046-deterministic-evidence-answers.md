# W-046 - Deterministic evidence answers

**Phase:** Phase 12 - Brief gaps: evidence engine  
**Brief ref:** G1  
**Depends on:** W-007, W-011  
**Status:** DONE

## Scope

Every canvas response carries answer {headline, facts[{label,value,unit,n,period,releaseId}], accountsMentioning?} assembled by templates from released numbers only, for overview, before/after, comparison, distribution, cohort, reader and discovery. Counts of written accounts come from published, non-withdrawn testimony with topic readings and are never stated below 5. Never a model opinion.

## Acceptance criteria

- [x] Every fact cites a release present in the payload, and the headline repeats only numbers from those facts.
- [x] A before/after headline states both measured values with n and period and names any other documented event inside the window.
- [x] Distribution answers read the published bands and a documented median only; no value is synthesized.
- [x] No account count from 1 to 4 appears in a headline, a fact or a topic notice.
- [x] Fictional employers are labeled in every headline and fact that names them, and a selected group is named so a group number never reads as the employer's.
- [x] The headline answers the measure the question asked about: a measure the question names (manager trust, executive trust) or else a measure of the applied topic, in every view; it never states another measure instead, and when the asked measure has no published value it says so.
